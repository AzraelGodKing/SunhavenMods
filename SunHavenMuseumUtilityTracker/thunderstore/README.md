# S.M.U.T. - Sun Haven Museum Utility Tracker

**Version 3.1.3** — Track your museum donation progress across all three halls (Hall of Gems, Hall of Culture, Aquarium) in Sun Haven. Manual tracking, per-character saves, item icons, search and filter.

**2.2.7:** Config file now uses `BepInEx/config/SunHavenMuseumUtilityTracker.cfg` (auto-migrates values from the legacy GUID-named config on first load).

## Features

- **Donation Tracking** - See which items you've donated and which you still need
- **Three Halls** - Hall of Gems, Hall of Culture, and Aquarium
- **Progress Stats** - Track your completion percentage
- **Item Icons** - Visual display of all museum items
- **Per-Character Saves** - Separate tracking for each save file

## Usage

Press **Ctrl+C** (configurable) to open the museum tracker UI.

## Installation

1. Install BepInEx 5.x
2. Place `SunHavenMuseumUtilityTracker.dll` in `BepInEx/plugins/`
3. Launch the game. Open tracker: **Ctrl+C**.

## Configuration

Edit `BepInEx/config/SunHavenMuseumUtilityTracker.cfg` to customize settings.
