Haven's Almanac brings supported Sun Haven mods together in one place: a compact HUD for at-a-glance lines, a full dashboard for detail, and a daily briefing for birthdays, tasks, museum progress, and more. It soft-depends on each integration — only installed mods appear.

On startup the mod can check for updates (toggle in config). HUD, dashboard, and briefing share a configurable UI scale (0.5–2.5×). On the main menu the Almanac hides its UI until you load into the world.

Quick Controls

Ctrl + F5
Toggle Dashboard (default: F5 with Ctrl required)
F4
Toggle HUD
Esc
Dismiss Briefing

Core Features

📊

Compact HUD

An always-visible, draggable widget showing a one-line status summary for each installed mod. Position it anywhere — your placement is saved across sessions.

📋

Full Dashboard

A comprehensive scrollable window with collapsible sections for every mod. Toggle with Ctrl+F5 for a detailed view of all your mod data in one place.

☀️

Daily Briefing

Summary popup after you load in and when a new day starts (sleep / day roll). Only opens when there's something noteworthy — today's birthdays, active tasks, or museum progress near completion. Dismiss with the button, Esc, or let the optional auto-dismiss countdown close it for you.

🔗

Soft Dependencies

No hard requirements on any mod. The Almanac detects which mods are installed and only shows sections for the ones you have. At least one is needed.

🔄

Auto-Refresh

Data refreshes automatically every few seconds. Switch characters and the Almanac updates. Sleep overnight and the briefing re-triggers with fresh data.

🎨

Themed UI

Warm parchment and gold aesthetic that fits Sun Haven's cozy atmosphere. All windows are draggable and remember their position.

Supported Mods

Haven's Almanac reads from these mods and displays their data. Install any combination.

📝

Sun Haven Todo

HUD: active count and completion %. Dashboard: totals, progress bar, and up to five High/Urgent tasks. Briefing: open-task and high-priority counts.

🎂

Birthday Reminder

HUD: today’s birthday and ungifted counts. Dashboard: full list with gifted status and gift hints. Briefing: each birthday NPC and reminders for ungifted.

🏛

S.M.U.T.

HUD: completion % and donated/total. Dashboard: progress bar and items still needed. Briefing: near-completion nudge when five or fewer items remain.

📦

Senpai's Chest

HUD and dashboard: configured smart-chest count for this character. No briefing panel.

🔒

The Vault

HUD: stored currency-type count. Dashboard: up to ten balances with names. No briefing panel.

⚔️

Haven's Birthright

HUD: current race and active bonus count. Dashboard: race name and each bonus with formatted values. No briefing panel.

🛠️

HavenDevTools

HUD: Active/Inactive authorization. Dashboard: status and player name. No briefing panel.

🌽

Crop Optimizer

HUD: planted count and projected sell total. Dashboard: summary plus top five crops by projected gold. No briefing panel.

🎁

Gifting Assistant

When integration is on: HUD pending/roster counts; dashboard lists remaining NPCs with priority; briefing covers pending, high, and urgent breakdowns.

Not integrated yet: Faster Races, Trinket Fortune, and Haven’s Respec do not expose Almanac panels; other mods above register automatically when their plugins are present.

Built-in: Mod Health

Always on — no companion mod required. The Almanac's Mod Health panel aggregates SunhavenMods.Shared.VersionChecker telemetry across every mod in the repo.

➕

Mod Health

One row per mod that registers a version check on startup — last-check timestamp and cumulative exception count. Each mod compiles its own copy of VersionChecker into its DLL, so the Almanac reflects across every loaded assembly to merge them into one dashboard view; friendly plugin names come from Chainloader.PluginInfos. A mod that never calls CheckForUpdate won't appear.

How It Works

1

Install Your Mods

Install Haven's Almanac alongside any combination of supported mods. At least one is required for content to display.

2

Load Into the Game

The Almanac detects installed mods on startup and initializes data providers for each one. The HUD appears automatically.

3

Check Your Briefing

After load-in, the briefing can appear with a fresh summary. After you sleep and the game advances to a new day, it can show again. Dismiss with the button or Esc (or set an auto-dismiss timer in config).

4

Open the Dashboard

Press Ctrl + F5 anytime for the full dashboard with detailed sections from every installed mod.

Configuration

Setting Default Description
Hotkeys → DashboardToggleKey F5 Key to toggle the full dashboard (with Ctrl if required below)
Hotkeys → DashboardRequireCtrl true When true, hold Ctrl while pressing the dashboard key (default Ctrl+F5)
Hotkeys → HUDToggleKey F4 Toggle HUD visibility
HUD → Enabled true Show the compact HUD
HUD → PositionX / PositionY -1 / -1 Saved HUD position (-1 = use default until you drag)
DailyBriefing → Enabled true Show the daily briefing
DailyBriefing → AutoDismissSeconds 0 Auto-close briefing after N seconds; a live "Auto-dismissing in Ns" countdown renders under the Dismiss button (0 = manual only)
Updates → CheckForUpdates true Check for a newer Almanac release on startup
Display → UIScale 1.0 Scale HUD, dashboard, and briefing (allowed range 0.5–2.5)

Configuration file: BepInEx/config/HavensAlmanac.cfg (auto-migrated from the legacy com.azraelgodking.havensalmanac.cfg on first load of 1.0.5+).
