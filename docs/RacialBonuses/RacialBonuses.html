Chronicle of Revisions

v2.0.0
📜

v2.0.0

Changing saves or characters—and Fire/Water Elemental behavior after loads and F9—is more reliable. The code was reorganized for upkeep, and the mod keeps its hidden runner alive with shared SceneRootSurvivor instead of a third-party Keep Alive mod.

v1.4.3
🔧

Input focus & bonus transfers

Hotkeys defer while typing in chat, console, or UI fields (TextInputFocusGuard). Optional [BonusTransfers] mirrors passive table bonuses between races (TargetRace|SourceRace|BonusType), default off.

v1.4.0
🔄

Save-load fix

Loading another save without the main menu fully resets race detection, abilities, and caches so they match the loaded character. F12 reloads config from disk.

v1.3.x
🐱

Amari Cat rework

New passives: Feline Grace, Predator’s Strike, Keen Senses. Nine Lives is a passive cheat-death (chance cap 60%); optional perf toggle if fast weapons stutter.

v1.3.0
✨

Celestial Bloodlines

Angels and Demons get Font of Light (mana for gold) and Soul Harvest (gold on kill at HP cost). Press F9 anytime to toggle; only applies to the race you picked.

v1.2.3
⚙

Chronicle Update

Documentation and code comment updates.

v1.2.0 / v1.2.1
🌊

Elemental Awakening

Fire and Water Elementals get unique actives that run automatically. Drawbacks and conditional synergies added; F9 toggles where applicable.

v1.0.0
🚀

📖 Integration with Haven’s Almanac

When Haven’s Almanac is installed, Haven’s Birthright registers automatically:

  • HUD line — current race and how many racial bonuses are active (or “No race set”).
  • Dashboard panel — race name and each active bonus with its formatted value.
  • Daily briefing — not included; racial bonuses are static per character, not a daily checklist.
