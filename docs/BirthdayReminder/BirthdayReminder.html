Never Miss a Birthday in Sun Haven

v2.1.4
★ ★ ★
Thunderstore — Nexus Mods — Combined —

A Squirrel's Birthday Reminder automatically notifies you when NPCs have birthdays in Sun Haven. Wake up each morning to see who's celebrating, get personalized gift suggestions for loved and liked items, and track who you've already gifted. Build friendships faster by never missing an opportunity to give the perfect gift!

Quick Controls

B
Toggle Birthday HUD

🎁 Smart Gift Suggestions

The HUD shows 3 random gift suggestions from each NPC's loved and liked items. Click "Show All Gifts" to see the complete list of preferred items for planning ahead!

📝 Todo Integration

When Sun Haven Todo is installed, birthday reminders are automatically added as todo tasks each morning. When you give an NPC their birthday gift, the todo is auto-completed for you — no manual tracking needed!

Party Planning Guide

1

Wake Up & Check

When your character wakes up each morning, the Birthday HUD will automatically appear if any NPCs have birthdays that day.

2

Browse Gift Ideas

The HUD shows 3 random gift suggestions for each birthday NPC. Click "Show All Gifts" to see the complete list of loved and liked items.

3

Deliver the Gift

Find the NPC in the game and give them one of their preferred gifts. Birthday gifts give bonus friendship points!

4

Mark Complete

Click the "Mark Gifted" button next to an NPC's name to track that you've given them their birthday gift.

5

Hide Until Tomorrow

Press B to toggle the Birthday HUD on or off at any time. The HUD auto-hides after a configurable duration.

RSVP (Installation)

📦

1. Install BepInEx

Download and install BepInEx 5.x for Unity games if you haven't already.

📥

2. Download Birthday Reminder

Get BirthdayReminder.dll from the releases page or Nexus Mods.

📁

3. Install the Mod

Place the DLL in your BepInEx/plugins/ folder.

🎮

4. Join the Party!

Launch Sun Haven and sleep until the next birthday to see the HUD in action!

Settings

Setting Default Description
ToggleKey B Key to toggle the Birthday HUD on/off
AutoHideDuration 30 Seconds before the HUD auto-hides (0 to disable)
DebugMode false Enable debug logging and test features

Configuration file located at: BepInEx/config/com.azraelgodking.squirrelsbirthdayreminder.cfg

📖 Integration with Haven’s Almanac

When Haven’s Almanac is installed, Birthday Reminder registers automatically. Each morning the Almanac reads today’s birthday list and gifted status:

  • HUD line — how many NPCs have birthdays today and how many are still ungifted (or “No birthdays”).
  • Dashboard panel — full list of today’s NPCs with gifted / not-gifted status and gift hints when available.
  • Daily briefing — each birthday NPC when anyone celebrates today, plus a reminder line when gifts are still owed.
