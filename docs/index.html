Install in Four Steps

Built for Sun Haven on PC with BepInEx 5.x. Exact game-build compatibility varies by release — check each mod's page, and BepInEx/LogOutput.log if a plugin fails to load.

1

Install BepInEx

Download BepInEx 5.x for Unity games and unzip it into your Sun Haven folder. Launch the game once so it generates its folders.

2

Download the mods

Grab the latest releases from Thunderstore or Nexus Mods — or use a mod manager like r2modman.

3

Drop in the DLLs

Place each mod's DLL (and any packaged files) into BepInEx/plugins/. Subfolders are fine.

4

Play

Launch Sun Haven. Mods activate automatically — check each mod's page for hotkeys and config options.

Frequently Asked

A mod didn't load after installing?

Make sure BepInEx 5.x is installed correctly and the mod DLL sits in BepInEx/plugins/. Check BepInEx/LogOutput.log for errors, and confirm you're on a compatible game version.

Where are the config files?

In BepInEx/config/ inside your Sun Haven game folder — one .cfg per mod. Edit them with any text editor while the game is closed, or use in-game settings where a mod supports them.

Can I run several mods at once?

Yes — all mods here are designed to work together with no conflicts, and several form powerful combinations:

  • Senpai's Chest + S.M.U.T. — auto-excludes already-donated museum items from sorting
  • Birthday Reminder + Todo — birthday gift reminders auto-create todos that complete when you give the gift
  • Gifting Assistant + Todo — the daily roster pushes “Gift {NPC} today” tasks that auto-complete when you gift
  • Gifting Assistant + Birthday Reminder + Almanac — birthday NPCs surface in the roster; progress appears on the Almanac dashboard
  • Senpai's Chest + S.M.U.T. + Todo — undonated museum items found in chests auto-create reminders that complete on donation

Every combination is optional — each mod works perfectly on its own.

How do I update a mod?

Replace the old DLL in BepInEx/plugins/ with the new version — config settings and save data are preserved automatically. With r2modman or Thunderstore, updates are handled for you.

My settings changed after upgrading?

If a mod adds new config options, BepInEx may regenerate the config file. Existing settings are preserved, but new options start at their defaults — check the .cfg file to verify your preferences.
