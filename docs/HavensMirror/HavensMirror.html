Haven's Mirror shows a custom player bust during dialogue. Drop PNGs into a gallery folder — one per look. Optional config can keep NPC portraits (and seasonal outfits) on a look you choose. Reload from disk with a hotkey; no restart required.

Where portraits go

On launch the mod scans your character saves and creates empty folders. Empty folders are ignored until you add PNGs. gallery/_shared/ is the fallback for every character.

BepInEx/ plugins/ HavensMirror/ gallery

_shared

Fallback looks used when a character folder is empty or a slot file is missing.

<CharacterName>

Created from your saves. Drop PNGs here to override the shared gallery for that farmer.

Missing slots reuse the first PNG found in that folder.

Expected file names

  • Spring spring.png Default / spring
  • Summer summer.png Warm season
  • Autumn autumn.png Fall season
  • Winter winter.png Cold season
  • Vows vows.png Wedding / ceremony
  • Shore shore.png Swimsuit / beach
  • Costume costume.png Halloween / costume

Features

PNG gallery

Per-character folders under gallery/, with a shared fallback. Missing slots reuse the first PNG found.

Season & special looks

Spring, summer, autumn, winter, vows, shore, and costume files map to dialogue contexts.

Hotkey reload

Press Ctrl+F8 (configurable) to reload PNGs from disk while playing.

Forced look

Optional override keeps NPC dialogue busts (and seasonal body outfits) on a look you choose.

Configuration

BepInEx/config/HavensMirror.cfg
Setting Default Description
Enabled true Master switch
GalleryFolderName gallery Folder under the plugin directory for portraits
SharedFolderName _shared Fallback folder when the character folder is empty
ForcedLook (blank) Spring / Summer / Autumn / Winter / Vows / Shore / Costume
ReloadModifier + ReloadKey LeftControl + F8 Reload PNGs from disk

Installation

  1. 1

    Install BepInEx

    Install BepInEx 5.x for Sun Haven if you haven't already.

  2. 2

    Download Haven's Mirror

    Get HavensMirror.dll from Nexus Mods, Thunderstore, or GitHub Releases — or build from this repo.

  3. 3

    Install & add portraits

    Place the DLL in BepInEx/plugins/HavensMirror/, then drop PNGs into gallery/_shared/ or a character-named subfolder.
