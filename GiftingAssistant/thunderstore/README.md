# Gifting Assistant

**Version 1.1.4**

Daily gift routine planner for Sun Haven.

- Per-character NPC gift roster
- Loved/liked gift suggestions with item icons
- Tracks who you've gifted today
- Priority sorting and optional Todo/Birthday integrations

Default hotkey: **Ctrl + G**

Config: `BepInEx/config/GiftingAssistant.cfg`
